## Architecture invariants confirmed

- `is_canonical_illustration=False` default on all `GalleryItemRecord` — images never become canon automatically
- `ImageEnqueueService.enqueue()` is separate from phase runner; phase runner never imports it
- `ImageQCService.run_technical_qc_and_record()` swallows QC failure into status fields — caller never receives an exception from image failure
- `FakeComfyUI` / `FakeObjectStore` are the CI defaults; no live HTTP in tests
- All model calls deferred — no model calls in CI test suite (no live markers used)
- Idempotent enqueue: duplicate `idempotency_key` returns existing record without insert

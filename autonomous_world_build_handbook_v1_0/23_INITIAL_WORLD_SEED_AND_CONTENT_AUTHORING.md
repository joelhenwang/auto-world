**Seed ID:** `caldris-embervale-v1`  
**Primary owners:** `seed`, domain/content validation, world-authoring tools  
**Required reading:** `02`, `08`–`11`, `19`, `20`, `22`

---

## 1. Purpose

This document defines the machine-readable seed format, validation and import process, original starter world used for Stages 0–3, initial focus characters, locations, routes, factions, magic foundations, content constraints, and how model-generated additions become canon.

The seed is deliberately bounded. It is large enough to test coherent autonomous behaviour, but small enough that coding agents can understand every initial fact while debugging.

The content is original and must not be converted into a recognizable copyrighted anime franchise or a direct imitation of one.

---

## 2. Seed goals

The starter seed must support:

- Stage 0 database/migration/engine fixtures;
- Stage 1 two-character three-phase day;
- Stage 2 four-character seven-day simulation;
- Stage 3 one-month arc, travel, factions, magic, injuries, and RAG;
- Stage 4 visual references;
- eventual Stage 5 lineage without predetermining relationships or children.

It should create opportunities, not a mandatory script.

## 5. Identifier policy

Runtime entities use application-generated UUIDv7 values. Seeded entities use deterministic UUIDv5 values derived from:

```text
namespace_uuid + canonical seed path
```

Example names:

```text
world/caldris
region/embervale-march
location/veycross/cinder-lantern-inn
character/mira-talren
```

This exception makes reseeding and fixture references stable. The importer records `seed_key` and rejects conflicting content for an already imported version.

Human-readable names are never used as foreign keys.

## 9. Magic: Resonance

### 9.1 Foundation

Lumen is an ambient field that responds to repeated pattern, intention, material resonance, and trained attention. Magic is called Resonance because practitioners shape Lumen through stable patterns: spoken cadence, gesture, glyph, music, crafted form, breath, or combinations.

### 9.2 Hard rules

1. Effects require a pattern the caster understands or an explicitly risky improvisation.
2. Mana is the practitioner’s short-term capacity to sustain a pattern.
3. Affinity makes certain patterns easier; it does not make other schools impossible by definition.
4. Larger range, duration, precision, or force increases cost and instability.
5. No ordinary spell creates matter permanently from nothing.
6. No ordinary spell reads an unexpressed complete mind.
7. Memory magic can evoke impressions or transfer bounded experiences only through specialized mechanisms and consent/force rules.
8. Teleportation is limited to short displacement or prepared anchored gates; no casual continental travel.
9. Healing accelerates or guides biology and can stabilize, but cannot trivially replace destroyed organs or erase all consequences.
10. Returning the dead requires the legendary Recall Concord: a preserved identity anchor, a willing viable vessel/body, multiple master resonators, enormous cost, and uncertain memory consequences.
11. Magic can fail, misfire, exhaust, injure, reveal the caster, or create delayed instability.
12. World-rule changes require versioned lore events.

### 9.3 Schools

```yaml
schools:
  - id: weave
    name: Weave
    purpose: shaping force, barriers, bindings, and movement
  - id: ember
    name: Ember
    purpose: heat, light, combustion, and energy transfer
  - id: veil
    name: Veil
    purpose: concealment, sensory distortion, and silence
  - id: mend
    name: Mend
    purpose: stabilization, healing guidance, and material repair
  - id: echo
    name: Echo
    purpose: traces, impressions, signals, and bounded memory resonance
  - id: green
    name: Green
    purpose: plant growth, soil, toxins, and living ecosystems
```

### 9.4 Ashglass

Ashglass is mineralized Lumen formed after the Ashfall. It can store or distort patterns. It is useful, regulated, and dangerous when cracked or overcharged.

### 9.5 Initial accessibility

- Mira has weak Echo/Veil sensitivity and no reliable combat spell.
- Dain has low general sensitivity and one practical Weave bracing technique.
- Iri is a trained novice in Echo and Mend.
- Torren has practical Ember/Weave craft patterns.

No initial character is an elite mage.

## 25. Seed validation

Before import:

- manifest/checksums;
- schema version;
- unique keys and deterministic IDs;
- all references resolve;
- route graph consistency;
- age/content rules;
- stat/resource/potential ranges;
- active card/state coherence;
- known spells exist and prerequisites make sense;
- relationship dimensions in range;
- private/public/Director-only knowledge separated;
- no duplicate entity aliases causing ambiguity;
- no copyrighted franchise/living-artist references;
- no executable or remote content;
- no secrets/API keys.

Produce a report grouped by error/warning/info.

## 26. Import transaction

1. acquire world-seed lock;
2. verify no conflicting world or seed version;
3. generate/resolve deterministic IDs;
4. insert world/config/calendar/rules;
5. insert entity registry;
6. insert locations/routes/lore/factions;
7. insert characters/cards/state/stats/skills/magic;
8. insert relationships/goals/beliefs/items;
9. create initial `WORLD_SEEDED` event with manifest hash;
10. create projections and initial snapshot;
11. commit;
12. output import report.

If any required row fails, roll back the entire seed.

## 27. Model-generated content authoring flow

For new lore, NPC, location, or arc content:

```text
proposal
  → schema validation
  → duplicate search
  → lore/map/timeline/content validation
  → privilege and budget validation
  → resolver or human review where required
  → canonical creation event
  → entity/lore projection
  → perspective observation/discovery as appropriate
```

Generated prose is not written directly into seed source files during runtime. Runtime creations belong to event history. A curated later seed version may deliberately incorporate accepted runtime patterns after review.

## 28. Human content-edit workflow

1. edit source YAML;
2. run formatter/schema validator;
3. run reference graph validation;
4. run content and copyright-name scan;
5. regenerate manifest checksums;
6. run seed import into empty database;
7. run Stage 0/1 scenario;
8. review generated cards/context token size;
9. increment content version;
10. commit source, checksums, tests, and change note.

Do not mutate an already imported live world merely by editing seed YAML. Use deity/import migration commands or start a new development world.

## 31. Definition of done

The initial seed is complete when:

- every file validates and imports atomically;
- IDs and references are deterministic;
- four distinct focus characters have evidence-rich but non-prescriptive cards;
- initial secrets and beliefs are perspective-isolated;
- map/routes support staged travel;
- magic has enforceable hard rules;
- factions create tension without a predefined villain;
- the first day can be quiet and the first month can develop into multiple plausible arcs;
- content is original, age-safe, and suitable for visual authoring;
- seed changes are versioned and tested rather than silently mutating live canon.
